# Question 50: Pow(x, n)

## Problem Description
Implement `pow(x, n)`, which calculates `x` raised to the power `n` (i.e., `x^n`).

## Step-by-Step Explanation

1. **Handle Base Cases:**
   - If `n == 0`, return `1.0` (any number raised to the power of 0 is 1).
   - If `x == 1.0`, return `1.0` (1 raised to any power is 1).
   - If `x == -1.0`, return `1.0` if `n` is even, otherwise return `-1.0`.
   - If `x == 0.0`, return `0.0` (0 raised to any power is 0).

2. **Handle Negative Exponents:**
   - If `n` is negative, invert `x` (i.e., `x = 1.0 / x`) and make `n` positive.

3. **Use Exponentiation by Squaring:**
   - Initialize `result` to `1.0`.
   - While `n > 0`:
     - If `n` is odd, multiply `result` by `x`.
     - Square `x` and halve `n`.

4. **Return the Result:**
   - Return the computed `result`.

## Code Implementation

```java
class Solution_Q50 {
    public double myPow(double x, int n) {
        if (n == 0) return 1.0;
        if (x == 1.0) return 1.0;
        if (x == -1.0) return (n % 2 == 0) ? 1.0 : -1.0;
        if (x == 0.0) return 0.0;

        long exp = n;
        double base = x;
        if (exp < 0) {
            base = 1.0 / base;
            exp = -exp;
        }

        double result = 1.0;
        while (exp > 0) {
            if (exp % 2 == 1) result *= base;
            base *= base;
            exp /= 2;
        }
        return result;
    }
}
```
