# Question 1390: Four Divisors

## Problem Description
Given an integer array `nums`, return the sum of divisors of the integers in the array that have exactly four divisors. If there is no such integer, return 0.

## Step-by-Step Explanation

1. **Understand the Problem:**
   - For each number in the array, find all its divisors.
   - If the number has exactly four divisors, add the sum of those divisors to the total.

2. **Iterate Through the Array:**
   - For each number `x` in the array, initialize `cnt` (count of divisors) and `sum` (sum of divisors) to 0.

3. **Find Divisors:**
   - Iterate through all possible divisors `d` from 1 to the square root of `x`.
   - If `d` divides `x`, calculate the corresponding divisor `e = x / d`.
   - If `d == e`, increment `cnt` by 1 and add `d` to `sum`.
   - Otherwise, increment `cnt` by 2 and add both `d` and `e` to `sum`.

4. **Check for Exactly Four Divisors:**
   - If `cnt == 4`, add `sum` to the total.

5. **Return the Result:**
   - Return the total sum of divisors for numbers with exactly four divisors.

## Code Implementation

```java
class Solution_Q1390 {
    public int sumFourDivisors(int[] nums) {
        int total = 0;
        for (int x : nums) {
            int cnt = 0, sum = 0, r = (int)Math.sqrt(x);
            for (int d = 1; d <= r && cnt <= 4; d++) {
                if (x % d == 0) {
                    int e = x / d;
                    if (d == e) { cnt++; sum += d; }
                    else { cnt += 2; sum += d + e; }
                }
            }
            if (cnt == 4) total += sum;
        }
        return total;
    }
}
```
