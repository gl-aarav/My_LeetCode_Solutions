# Question 74: Search a 2D Matrix

## Problem Description
Write an efficient algorithm that searches for a value in an `m x n` matrix. This matrix has the following properties:

1. Integers in each row are sorted in ascending order.
2. The first integer of each row is greater than the last integer of the previous row.

## Step-by-Step Explanation

1. **Flatten the Matrix Conceptually:**
   - Treat the `m x n` matrix as a sorted 1D array.
   - The element at index `mid` in the 1D array corresponds to `matrix[mid / n][mid % n]` in the 2D matrix.

2. **Binary Search:**
   - Use binary search to find the target value.
   - Initialize `lo` to 0 and `hi` to `m * n - 1`.
   - While `lo <= hi`:
     - Calculate `mid = lo + (hi - lo) / 2`.
     - Map `mid` to the 2D matrix using `r = mid / n` (row) and `c = mid % n` (column).
     - Compare the value at `matrix[r][c]` with the target.
       - If equal, return `true`.
       - If less than the target, move `lo` to `mid + 1`.
       - If greater than the target, move `hi` to `mid - 1`.

3. **Return the Result:**
   - If the loop ends without finding the target, return `false`.

## Code Implementation

```java
class Solution_Q74 {
    public boolean searchMatrix(int[][] matrix, int target) {
        if (matrix == null || matrix.length == 0 || matrix[0].length == 0) return false;
        int m = matrix.length, n = matrix[0].length;
        int lo = 0, hi = m * n - 1;
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            int r = mid / n, c = mid % n;
            int v = matrix[r][c];
            if (v == target) return true;
            if (v < target) lo = mid + 1;
            else hi = mid - 1;
        }
        return false;
    }
}
```
